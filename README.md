Deskripsi Aplikasi

NOIRÉ Café merupakan aplikasi menu kafe berbasis PHP yang dibuat dengan menerapkan konsep Object-Oriented Programming (OOP). Aplikasi ini menampilkan menu makanan, bakery, dan minuman, serta menyediakan informasi statistik mengenai jumlah menu dan menu best seller.

Dalam pengembangannya, aplikasi ini menggunakan parent class Menu dan subclass Makanan serta Minuman. Konsep OOP yang diterapkan meliputi encapsulation, inheritance, polymorphism, getter dan setter, serta constructor.

Output program ditampilkan pada halaman index.php, termasuk kotak statistik yang dihitung dari objek menu dan ditampilkan menggunakan echo.

Kesesuaian dengan Ketentuan Tugas

1. Membuat parent class dengan properti dan method publik.

2. Membuat subclass yang mewarisi parent class.

3. Menerapkan konsep OOP berupa encapsulation, inheritance, polymorphism, getter dan setter, serta constructor.

4. Menampilkan output program pada halaman index.php menggunakan echo.

Demikian tugas aplikasi NOIRÉ Café ini saya buat sebagai penerapan materi Object-Oriented Programming (OOP) menggunakan PHP.
